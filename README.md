# 🎓 Білім — мұғалімдер мен оқушылар сайты

Мұғалімнің жұмысын жеңілдететін сайт: кабинет, расписание, слайд-конструктор, Kahoot-тай тесттер және топтық ойындар (QR арқылы оқушы қосылуы).

## Іске қосу

```bash
cd school-site
python3 -m http.server 8341 --bind 127.0.0.1
# ашыңыз: http://127.0.0.1:8341
```

## Беттер

| Бет | Сілтеме | Кімге |
|---|---|---|
| Басты | `index.html` | барлығы |
| Кіру/Тіркелу | `auth.html` | барлығы |
| Мұғалім кабинеті | `cabinet.html` | 🔒 тек мұғалім |
| Сабақ слайдтары + ойындар | `slides.html` | 🔒 тек мұғалім |
| Көрсету режимі | `present.html?lesson=ID` | мұғалім (сабақта) |
| Ойынға қосылу | `join.html?t=quiz|board&room=CODE` | оқушы (QR арқылы) |

## Тіркелу және кіру

- **Email/пароль**: `auth.html` → «Тіркелу» → рөл: Мұғалім немесе Оқушы.
  Пароль SHA-256 хэшімен браузерде сақталады (localStorage).
- **Google**: `config.js` файлында `BILIM_FIREBASE` конфигурациясын толтырған соң
  «Google арқылы кіру» түймесі іске қосылады (нұсқау төменде).
- Мұғалім тіркелгенде оған жеке кабинет жазылады (сертификаттар, сыныптар,
  расписание — бәрі сол мұғалімге).
- Кабинет пен слайдтар беті тек мұғалім кіргенде ашылады; оқушы/қонақ —
  «Кіру» экранына түседі.

## Google кіруді қосу (Firebase, тегін)

1. [console.firebase.google.com](https://console.firebase.google.com) → **Create a project** (мыс: `bilim`)
2. **Build → Authentication → Get started** → **Sign-in method** табында:
   - **Email/Password** — қосу
   - **Google** — қосу (өзіңіздің жұмыс email-іңізді жазыңыз)
3. **Project settings (⚙) → General → Your apps** → Web app `</>` →
   конфигурацияны көшіріп алыңыз (`firebaseConfig`)
4. `config.js` файлында `window.BILIM_FIREBASE = null;` орнына:
   ```js
   window.BILIM_FIREBASE = {
     apiKey: "AIza...",
     authDomain: "bilim.firebaseapp.com",
     projectId: "bilim"
   };
   ```
5. **Authentication → Settings → Authorized domains** тізіміне сайт доменіңізді қосыңыз
   (жергілікті тест үшін `127.0.0.1` қосылады)

## Қалай жұмыс істейді

- **Деректер**: мұғалімдер, кабинет деректері, слайдтар, тесттер — браузердің
  localStorage-ында (демо режим). Барлығы сол компьютердің браузерінде сақталады.
- **Онлайн-ойындар**: WebRTC (PeerJS) арқылы тікелей байланыс — аралық сервер
  жоқ. Интернет қажет. Мұғалім = host, оқушылар QR арқылы кіреді.
- QR-суреттер `api.qrserver.com` арқылы жүктеледі.
